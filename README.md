# Claude Code Plugins

A curated collection of personal plugins for **Claude Code**, designed to extend and enhance developer workflows.

This repository acts as a lightweight **plugin marketplace**, where I publish, organize, and experiment with reusable tools tailored to my needs.

## Purpose

- Centralize custom Claude Code plugins
- Share reusable automation and developer utilities
- Experiment with plugin patterns inspired by the official ecosystem
- Provide a structured and versioned distribution space

## Philosophy

This project follows the spirit of the official Claude Code plugins while remaining:

- **Pragmatic**: built for real-world usage
- **Modular**: each plugin is independent and reusable
- **Transparent**: simple structure, easy to understand and adapt
- **Personal-first**: optimized for my workflows, but reusable by others

## Structure

Each plugin lives in its own directory and includes:

- Configuration / manifest
- Source code
- Usage documentation
- Examples when relevant

## Usage

Clone the repository and integrate the plugins you need into your Claude Code environment.  
Refer to each plugin’s README for specific instructions.
